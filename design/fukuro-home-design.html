Design reference for the app redesign. Each frame is 396×812 CSS px, which maps 1:1 to dp on an Android device. Read the inline styles for exact colours, sizes, and spacing; the written spec in claude-code-prompt.md lists the same values as tokens. 5a is dark, 5b is light. The mini player and bottom nav stay light-on-dark in both themes.
